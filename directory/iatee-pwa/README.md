# iatee-pwa

Turn a web app into a Progressive Web App: installable on phones and desktops, an iPhone-app look, offline support and clean updates.

| Skill | What it does | When to use it |
|---|---|---|
| `pwa` | Makes a web app installable, offline-ready and safe to update, with an iPhone-app look: manifest, icons, splash screens, service worker, install button. | You want people to add your web app to their home screen or use it offline. |

Part of [Claude Skills](https://skills.garciabaertsch.com), a curated collection of Claude Code skills. This is the directory edition of the `frontend` plugin. The full collection, including plugins with hooks and scripts such as the skill suggester, installs from its own marketplace:

```text
/plugin marketplace add https://github.com/iatee/claude-skills.git
```
