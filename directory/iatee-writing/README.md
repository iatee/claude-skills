# iatee-writing

Write for people and for agents: drafting, shaping, teaching and re-pitching. Skills by Matt Pocock.

| Skill | What it does | When to use it |
|---|---|---|
| `teach` | Teaches you a concept step by step, using your own workspace as the example. | You want to understand something, not just have it done. |
| `wait-what` | Makes Claude re-explain its last message in plain, simple English. | Claude's last answer lost you. |
| `writing-for-agents` | How to write skills, CLAUDE.md and AGENTS.md files that agents follow well. | You're writing or editing a skill or agent instructions. |
| `writing-fragments` | Collects raw thoughts and fragments for a piece of writing, with no structure yet. | You're at the start of an article and have ideas but no outline. |
| `writing-shape` | Shapes raw material into an article, paragraph by paragraph. | You have the material and want it turned into a finished text. |

Part of [Claude Skills](https://skills.garciabaertsch.com), a curated collection of Claude Code skills. This is the directory edition of the `writing` plugin. The full collection, including plugins with hooks and scripts such as the skill suggester, installs from its own marketplace:

```text
/plugin marketplace add https://github.com/iatee/claude-skills.git
```
