# iatee-sessions

Carry work between sessions: handoffs to a fresh agent and session retrospectives. Skills by Matt Pocock.

| Skill | What it does | When to use it |
|---|---|---|
| `claude-handoff` | Hands the work to a new background agent that continues straight away. | You want the work to go on in the background while you do something else. |
| `handoff` | Writes a handoff document so a fresh session can continue the work. | The conversation is getting long or you'll continue another day. |
| `retro` | Runs a short retrospective on the session: what worked, what didn't, what to change. | A piece of work is finished and you want to learn from it. |

Part of [Claude Skills](https://skills.garciabaertsch.com), a curated collection of Claude Code skills. This is the directory edition of the `sessions` plugin. The full collection, including plugins with hooks and scripts such as the skill suggester, installs from its own marketplace:

```text
/plugin marketplace add https://github.com/iatee/claude-skills.git
```
